
# SQL Engineering Practice

A personal repository documenting my daily SQL practice
and progression toward professional Data Engineering.

## Tech Stack

- Microsoft SQL Server
- T-SQL
- Visual Studio Code
- Git & GitHub

## Repository Structure

- `practice/` — Daily SQL exercises organized by date
- `datasets/` — Reusable datasets for SQL practice
- `archive/` — Previous assignments, solutions, and reviews

## Topics Covered

- SQL Fundamentals
- Joins and Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregations and Grouping
- Set Operators
- Date and Time Functions
- Query Optimization
- Data Quality and Validation

## Practice Approach

Each daily SQL file contains problem descriptions,
solutions, and relevant technical notes.

My focus is on SQL correctness, readability,
performance, and engineering best practices.

## Environment

SQL scripts are written in T-SQL and practiced
using Microsoft SQL Server through VS Code.
