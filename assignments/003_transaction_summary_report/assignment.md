## Assignment 3 — Revised

You are a Data Engineer at an Australian fintech company.

The analytics team has submitted the following request:

> *"We need a monthly transaction summary report for the year 2024. For each month, show the total transaction amount, the number of transactions, and the average transaction amount. Break this down by transaction type and channel. Only include transactions that were not flagged.*
>
> *Additionally:*
> - *For each row, show what percentage of the total monthly transaction amount that specific channel represents within its transaction type*
> - *For each row, show the running total of transaction amount within each transaction type, ordered by month ascending*
> - *For each row, rank the channels within each transaction type and month by total transaction amount, with the highest amount ranked 1*
>
> *Sort by month ascending, then transaction type, then channel."*

The relevant table is `dbo.transactions`.

You have 3 attempts. Submit when ready.
